# 文档示例的验证边界

手册是实验性作者资料，文档检查不会授予资源权限或替代设备验收。

| 检查 | 覆盖 | 未证明的内容 |
| --- | --- | --- |
| Markdown 来源对照 | 代码块与 SDK 示例逐字一致；本地相对链接存在。遗漏标记或示例漂移导致 CI 失败。 | 中文正文的全部语义。 |
| Python 离线预检 | Manifest、静态 Node、打包和资源界限。 | 代码业务逻辑、权限批准。 |
| TypeScript / JS 语法 | Hello 与手册函数片段调用当前有限 SDK 类型。 | 动态输入与真实 Host 准入。 |
| Quick Start 脱仓库运行 | 仅复制 SDK 所需文件，在临时目录执行原命令并产生实际 `.dip`。 | 安装界面的首次作者体验、十分钟时长。 |
| 正式 Host 测试 | 实际包与 Hello VM；文档函数的 Activity、资源拒绝 / 批准、数据校验和生命周期。网络使用固定响应，链接使用测试 opener。 | 外部服务实时状态、系统浏览器、物理相机遮挡。 |

每个可执行代码块前都有 `sdk-source` 注释，它指向本 SDK 的源文件；检查器不会从 Markdown 执行任意 shell 文本。只运行已固定的 Quick Start 脚本，源码对照通过后才执行。JavaScript 片段不是额外完整插件，只有 Hello 模板可以直接打包。

先保留“首次作者按文档安装并点击”的验收门槛；在已有 T35 / T36 人工验收方便进行时一并安排，不自动要求新一轮长计时。没有真实走查之前不标记 T39 verified，也不宣称十分钟目标已达到。
