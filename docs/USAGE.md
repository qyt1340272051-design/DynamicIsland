# 使用说明

Dynamic Island 是 macOS 菜单栏应用，支持 macOS 26.0 或更高版本。当前尚无正式签名、公证的下载包；请按 [编译说明](BUILDING.md) 从源码运行。刘海 MacBook 是主要场景，无刘海屏幕和外接屏幕使用顶部居中的回退布局。

## 启动与菜单栏

1. 在 Xcode 运行 `Dynamic Island` scheme，或打开本地编译得到的 `Dynamic Island.app`。
2. App 不显示普通主窗口。找到菜单栏的岛形图标，选择“显示 Dynamic Island”或“隐藏 Dynamic Island”；退出时选择“退出”。
3. 将鼠标移到屏幕顶边的紧凑岛，稍候即可展开；移开鼠标后收起。将文件拖到岛上也会展开文件托盘。

如果没有看到面板，先检查菜单栏图标中的“显示 Dynamic Island”、当前主屏幕顶部、全屏 Space 和菜单栏自动隐藏设置。

## 音乐与音量

- 展开后选择音符图标。左侧是 Apple Music 的封面与曲目信息，右侧可播放/暂停、切换曲目、查看进度。歌曲播放期间，紧凑岛会显示小封面和动态指示。
- 下方的扬声器图标可静音/取消静音，`-`、`+` 按钮和滑杆调节系统默认输出设备的音量。某些数字输出设备可能不支持软件音量控制。
- 首次读取或控制 Apple Music 时，允许 macOS 的自动化权限请求。若曾拒绝，可在“系统设置 > 隐私与安全性 > 自动化”重新开启。当前仅支持系统“音乐”App，不支持第三方播放器。

## 文件托盘与 AirDrop

1. 从 Finder 将文件拖到岛上；展开后也可选择托盘图标查看暂存内容。
2. 点击“AirDrop”打开 macOS 系统分享界面；点击垃圾桶清空托盘。托盘中的文件也可拖出。
3. 导入会复制文件到应用沙盒的临时目录，不会移动原文件。托盘不是长期存储位置，清空托盘会删除临时副本；请保留原件。

## 计时工具

- 选择扳手图标，在“秒表 / 番茄钟 / 倒计时”之间切换。
- 番茄钟可选 15、25、45、60 分钟。倒计时用 `-`、`+` 按分钟调整，按住可连续调整；点击播放键开始或暂停，回转箭头重置。
- 计时期间紧凑岛显示当前功能图标与数据。倒计时和番茄钟结束时，岛自动展开；点击勾号确认并收起。
- 计时状态目前不会在 App 退出后恢复。

## 诊断与反馈

菜单栏选择“复制调试信息”，再选择“提交 Beta 反馈...”，即可把设备、屏幕和面板状态粘贴到结构化 Issue 表单。报告不收集用户名、设备序列号、文件名或歌曲信息；提交前仍请检查剪贴板文本和截图，避免泄露其他私人内容。

真机测试场景与问题等级见 [Beta 验收手册](BETA_TESTING.md)。
