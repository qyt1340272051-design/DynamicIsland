# 使用说明

Dynamic Island 是 macOS 菜单栏应用，支持 macOS 26.0 或更高版本。当前开发源码为 `0.6.1/build23`，公开 App 下载仍为 `v0.6.0-beta.2` / build 4，以[对应 Release](https://github.com/qyt1340272051-design/DynamicIsland/releases/tag/v0.6.0-beta.2)的实际资产为准，也可按[编译说明](BUILDING.md)从源码运行。测试 DMG 为未公证的 ad hoc 构建，不是 Developer ID 正式安装包。刘海 MacBook 是主要场景，无刘海屏幕和外接屏幕使用顶部居中的回退布局。

## 启动与菜单栏

1. 在 Xcode 运行 `Dynamic Island` scheme，或把测试 DMG 中的 `Dynamic Island.app` 拖到“应用程序”后尝试打开。测试包未经公证，若 macOS 拦截，请先核对 SHA-256 并确认来源可信，再到“系统设置 > 隐私与安全性”点击“仍要打开”、确认“打开”；参阅 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。无法放行时请联系设备管理员，不要关闭系统安全机制。
2. App 不显示普通主窗口，也不驻留 Dock。找到菜单栏的岛形图标，选择“显示 Dynamic Island”或“隐藏 Dynamic Island”；要彻底关闭应用，请选择“退出”。
3. 将鼠标移到屏幕顶边的紧凑岛，稍候即可展开；移开鼠标后收起。将文件拖到岛上也会展开文件托盘。

展开岛体后，点击右上角的电源图标会直接退出应用；菜单栏中的“退出”也会终止应用，而“隐藏 Dynamic Island”只隐藏岛体。

如果没有看到面板，先检查菜单栏图标中的“显示 Dynamic Island”、当前主屏幕顶部、全屏 Space 和菜单栏自动隐藏设置。

## 音乐与音量

- 展开后选择「主页」的音乐层。左侧是自动识别的播放器封面与曲目信息，右侧可播放/暂停、切换曲目、查看进度。歌曲播放期间，紧凑岛会显示小封面和动态指示。
- 下方的扬声器图标可静音/取消静音，`-`、`+` 按钮和滑杆调节系统默认输出设备的音量。某些数字输出设备可能不支持软件音量控制。
- 首次读取或控制 Apple Music 时，允许 macOS 的自动化权限请求。若曾拒绝，可在“系统设置 > 隐私与安全性 > 自动化”重新开启。第三方播放器通过下方的可选插件接入。
- 播放有明确时长的曲目时，鼠标移到进度条上会显示白色圆点；可直接拖动跳转，岛上时间会随拖动实时更新。

## 主页默认页面

在「设置 → 通用 → 主页 → 展开时主页默认页面」选择音乐、日历、课程或会议，选择会保存，每次重新展开时应用。展开期间可点击选层按钮或双指横向滑动自由切换；四层双向循环，会议继续向前回到音乐，音乐反向回到会议。每次手势只切一层，纵向日程列表和音乐滑块保留各自操作。

## 外观

展开 Dynamic Island，点击右上角齿轮进入「设置 → 外观」，选择「默认外观」「封面流光」「封面光晕」或「透明毛玻璃」。切换立即生效，并在本机保存。

「封面流光」将音乐封面的多种颜色透过模糊玻璃柔和扩散到背景板，适用于播放中的紧凑态和展开的音乐页。切歌或封面变化时更新颜色；缺失或无效封面、其他活动及工具页使用默认深色背景。背景保留暗色遮罩，文字和操作按钮保持清晰。

「封面光晕」以音乐封面的实际位置为光源，将封面的大体颜色向四周柔和扩散，越远越暗并渐变融入纯黑。播放中的紧凑态与展开音乐页均可使用；切歌或仅更新封面时自动改变颜色，缺失或无效封面及其他页面回到纯黑背景。

「透明毛玻璃」透出并模糊桌面壁纸与后方窗口，使用深色玻璃保证文字和按钮清晰，适用于紧凑态及音乐、托盘、计时和工具等展开页面。开启 macOS「辅助功能 → 显示 → 减少透明度」时，自动使用实色深色背景，仍保留外观选择。

## 文件托盘与 AirDrop

1. 从 Finder 将文件拖到岛上；展开后也可选择托盘图标查看暂存内容。
2. 将鼠标移到某个文件上，点击其左上角的红色减号可仅移除该文件；点击“AirDrop”打开 macOS 系统分享界面，点击垃圾桶则清空托盘。托盘中的文件也可拖出。
3. 点击托盘右上角的锁图标可固定展开的岛体，移开鼠标也不会收起；再次点击即可解锁。即使清空托盘，锁定状态仍会保持。
4. 导入会复制文件到应用沙盒的临时目录，不会移动原文件。托盘不是长期存储位置，清空托盘会删除临时副本；请保留原件。

## 内置计时

- 展开刘海，点击闹钟图标，在岛内直接切换「秒表 / 倒计时」。分配到计时区的插件也在同一切换栏内；番茄钟从 0.6.0 起作为独立插件提供。
- 倒计时用 `-`、`+` 按分钟调整，按住可连续调整；点击播放键开始或暂停，回转箭头重置。
- 运行时紧凑岛显示计时信息；内置倒计时完成页可点勾号确认并收起。计时状态不跨 App 退出保存。

## 插件管理与官方插件

菜单入口在屏幕右上角、时间和控制中心附近的横向岛形小图标，不是顶部中央的大岛体。点击该图标，选择「插件管理…」。

### 安装与启用

1. 在插件管理点击「发现」，再点击「刷新目录」。只有主动刷新才请求正式目录；打开窗口本身保持离线。
2. 在目录核对最低 Host 与来源，选中官方番茄钟或 GitHub 的「下载并查看」。等待摘要、归档和 Manifest 验证，再核对安装预览中的名称、版本与声明权限。
3. 点击「安装插件」。安装后保持停用，既不会自动授权，也不会运行插件。也可使用「导入插件」选择从[官方插件 Release](https://github.com/qyt1340272051-design/DynamicIsland/releases/tag/plugins-0.6.0)下载的 `.dip`，进入相同预览流程。
4. 回到插件管理，选中插件。阅读每项权限的说明，按需点「授权…」，在确认框点「允许此权限」；可拒绝不需要的权限。逐项决定后点「启用插件」。启用本身不会批准权限，拒绝的能力仍不可用。
5. 在「设置 → 插件 → 已安装」选中功能插件，用「显示区域」选择计时区或工具区。该选择保存在本机，重启后保留；修改不会启用插件或授予权限。纯音乐来源插件启用并授权后自动识别，不提供工具区域设置。
6. 展开刘海，点击闹钟（计时区）或工具按钮（工具区），再从岛内切换栏选择插件。切换栏支持横向滚动，选择时无需离开岛体。收起会清除本次工具选择，重新展开后可再次选择；计时区会显示内置计时。收起或隐藏工具不会结束已经开始的番茄计时。

插件管理可以停用、逐项撤销权限和卸载。卸载会停止并移除插件、撤销授权，已保存的插件数据保留。撤销后相关能力不可继续使用；代码或权限声明变化后需重新确认，旧包的批准不能自动沿用。目录只提供发现元数据，不证明发布者身份，没有自动安装、自动更新或自动授权。

### 可选音乐播放器

在含对应 helper 的开发 Host 0.6.1/build21 或更新版本中，可从插件发现目录下载 [QQ 音乐](plugin-system/examples/qq-music/README.md)与 [Spotify](plugin-system/examples/spotify/README.md)，也可从 [plugins-music-0.1.0 Release](https://github.com/qyt1340272051-design/DynamicIsland/releases/tag/plugins-music-0.1.0) 下载 `.dip` 后导入。当前公开的 0.6.0 App 不支持这两款音乐插件。

1. 在「设置 → 插件 → 发现」刷新目录，选择需要的包并点击「下载并查看」，核对预览后安装；本地导入会进入相同预览流程。
2. 分别批准 `media.read`（歌曲、状态、进度与封面）和 `media.control`（播放/暂停、上下曲、拖动进度），然后启用插件。只允许读取时可以显示歌曲，不能控制播放。
3. 在对应音乐客户端播放一首歌。Host 0.6.1/build23 起自动跟随系统当前活动音源，无需手动选择 App；「设置 → 通用 → 音乐播放器」显示识别状态和已启用来源。两个插件可同时安装，旧的手动来源偏好不再生效。
4. 在主页的音乐层使用现有封面、播放控制和进度条。控制要求该客户端持有系统当前活动媒体会话；若提示连接失败，回到该客户端恢复播放后重试。

插件不会启动播放器，不需要账户、Cookie、网络或辅助功能权限。客户端未运行时显示空闲状态；当前音源插件未安装、停用或未授权时提示尚未就绪，不读取歌曲，也不会转而控制其他播放器。音源切换后会清除旧歌曲，旧页面发出的按钮和进度请求不会重定向到新 App。系统未提供封面时显示占位图。真实多播放器切换、播放控制及持续收起态刷新仍需在客户端验收，不能以自动化路由测试代替。

### 两款官方插件

| 插件 | 权限与用途 | 使用范围 |
| --- | --- | --- |
| 番茄钟 0.2.1 | `storage.local`：保存预设和状态元数据；拒绝后仍可计时，设置不保存 | 15 / 25 / 45 / 60 分钟，开始 / 暂停 / 继续 / 结束；完成时发出应用内提示，不是系统通知，不自动开下一轮 |
| GitHub 0.1.0 | `network`：读取允许的公开 HTTPS API；`storage.local`：保存仓库选择和结果去重；`links.open`：按钮打开 Host 允许的 GitHub 网页 | 仅 `actions/checkout`、`cli/cli` 公开仓库；可切换、刷新、打开构建或 PR，不使用 Token，不支持私有仓库 |

番茄钟获准后可保存预设，但业务计时不跨 App 重启恢复。GitHub 拒绝网络权限时显示「网络未授权」；拒绝存储时设置不保存，拒绝打开网页时链接动作不可用。网络配额或服务错误会显示相应状态，公开 API 数据可能变化。

只安装你信任的插件。JavaScriptCore 和 Host 权限提供受限接口，不是每插件独立的操作系统安全边界；当前不能强制抢占无限循环 JavaScript。SuperIsland 兼容仅支持已实现的简单子集，不保证任意上游插件能运行。开发入口见 [SDK 文档](../SDK/docs/README.md)。

## 诊断与反馈

菜单栏选择“复制调试信息”，再选择“提交 Beta 反馈...”，即可把设备、屏幕和面板状态粘贴到结构化 Issue 表单。报告不收集用户名、设备序列号、文件名或歌曲信息；提交前仍请检查剪贴板文本和截图，避免泄露其他私人内容。

真机测试场景与问题等级见 [Beta 验收手册](BETA_TESTING.md)。
