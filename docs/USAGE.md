# 使用说明

Dynamic Island 是 macOS 菜单栏应用，支持 macOS 26.0 或更高版本。当前源码为 `0.6.0` 开发预览（候选 `v0.6.0-beta.2` / build 4），以[对应 Release](https://github.com/qyt1340272051-design/DynamicIsland/releases/tag/v0.6.0-beta.2)的实际资产为准，也可按[编译说明](BUILDING.md)从源码运行。测试 DMG 为未公证的 ad hoc 构建，不是 Developer ID 正式安装包。刘海 MacBook 是主要场景，无刘海屏幕和外接屏幕使用顶部居中的回退布局。

## 启动与菜单栏

1. 在 Xcode 运行 `Dynamic Island` scheme，或把测试 DMG 中的 `Dynamic Island.app` 拖到“应用程序”后尝试打开。测试包未经公证，若 macOS 拦截，请先核对 SHA-256 并确认来源可信，再到“系统设置 > 隐私与安全性”点击“仍要打开”、确认“打开”；参阅 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。无法放行时请联系设备管理员，不要关闭系统安全机制。
2. App 不显示普通主窗口，也不驻留 Dock。找到菜单栏的岛形图标，选择“显示 Dynamic Island”或“隐藏 Dynamic Island”；要彻底关闭应用，请选择“退出”。
3. 将鼠标移到屏幕顶边的紧凑岛，稍候即可展开；移开鼠标后收起。将文件拖到岛上也会展开文件托盘。

展开岛体后，点击右上角的电源图标会直接退出应用；菜单栏中的“退出”也会终止应用，而“隐藏 Dynamic Island”只隐藏岛体。

如果没有看到面板，先检查菜单栏图标中的“显示 Dynamic Island”、当前主屏幕顶部、全屏 Space 和菜单栏自动隐藏设置。

## 音乐与音量

- 展开后选择音符图标。左侧是 Apple Music 的封面与曲目信息，右侧可播放/暂停、切换曲目、查看进度。歌曲播放期间，紧凑岛会显示小封面和动态指示。
- 下方的扬声器图标可静音/取消静音，`-`、`+` 按钮和滑杆调节系统默认输出设备的音量。某些数字输出设备可能不支持软件音量控制。
- 首次读取或控制 Apple Music 时，允许 macOS 的自动化权限请求。若曾拒绝，可在“系统设置 > 隐私与安全性 > 自动化”重新开启。当前仅支持系统“音乐”App，不支持第三方播放器。
- 播放有明确时长的曲目时，鼠标移到进度条上会显示白色圆点；可直接拖动跳转，岛上时间会随拖动实时更新。

## 文件托盘与 AirDrop

1. 从 Finder 将文件拖到岛上；展开后也可选择托盘图标查看暂存内容。
2. 将鼠标移到某个文件上，点击其左上角的红色减号可仅移除该文件；点击“AirDrop”打开 macOS 系统分享界面，点击垃圾桶则清空托盘。托盘中的文件也可拖出。
3. 点击托盘右上角的锁图标可固定展开的岛体，移开鼠标也不会收起；再次点击即可解锁。即使清空托盘，锁定状态仍会保持。
4. 导入会复制文件到应用沙盒的临时目录，不会移动原文件。托盘不是长期存储位置，清空托盘会删除临时副本；请保留原件。

## 内置计时

- 展开刘海，点击闹钟图标，在工具菜单选择「内置计时」，再切换「秒表 / 倒计时」。番茄钟从 0.6.0 起作为独立插件提供。
- 倒计时用 `-`、`+` 按分钟调整，按住可连续调整；点击播放键开始或暂停，回转箭头重置。
- 运行时紧凑岛显示计时信息；内置倒计时完成页可点勾号确认并收起。计时状态不跨 App 退出保存。

## 插件管理与官方插件

菜单入口在屏幕右上角、时间和控制中心附近的横向岛形小图标，不是顶部中央的大岛体。点击该图标，选择「插件管理…」。

### 安装与启用

1. 在插件管理点击「发现」，再点击「刷新目录」。只有主动刷新才请求正式目录；打开窗口本身保持离线。
2. 在目录核对最低 Host 与来源，选中官方番茄钟或 GitHub 的「下载并查看」。等待摘要、归档和 Manifest 验证，再核对安装预览中的名称、版本与声明权限。
3. 点击「安装插件」。安装后保持停用，既不会自动授权，也不会运行插件。也可使用「导入插件」选择从[官方插件 Release](https://github.com/qyt1340272051-design/DynamicIsland/releases/tag/plugins-0.6.0)下载的 `.dip`，进入相同预览流程。
4. 回到插件管理，选中插件。阅读每项权限的说明，按需点「授权…」，在确认框点「允许此权限」；可拒绝不需要的权限。逐项决定后点「启用插件」。启用本身不会批准权限，拒绝的能力仍不可用。
5. 展开刘海，点击闹钟图标，从工具菜单选择已启用的插件。正常离开并收起后，重新展开回到内置计时；可再次从菜单选择插件。收起或隐藏工具不会结束已经开始的番茄计时。

插件管理可以停用、逐项撤销权限和卸载。卸载会停止并移除插件、撤销授权，已保存的插件数据保留。撤销后相关能力不可继续使用；代码或权限声明变化后需重新确认，旧包的批准不能自动沿用。目录只提供发现元数据，不证明发布者身份，没有自动安装、自动更新或自动授权。

### 两款官方插件

| 插件 | 权限与用途 | 使用范围 |
| --- | --- | --- |
| 番茄钟 0.2.1 | `storage.local`：保存预设和状态元数据；拒绝后仍可计时，设置不保存 | 15 / 25 / 45 / 60 分钟，开始 / 暂停 / 继续 / 结束；完成时发出应用内提示，不是系统通知，不自动开下一轮 |
| GitHub 0.1.0 | `network`：读取允许的公开 HTTPS API；`storage.local`：保存仓库选择和结果去重；`links.open`：按钮打开 Host 允许的 GitHub 网页 | 仅 `actions/checkout`、`cli/cli` 公开仓库；可切换、刷新、打开构建或 PR，不使用 Token，不支持私有仓库 |

番茄钟获准后可保存预设，但业务计时不跨 App 重启恢复。GitHub 拒绝网络权限时显示「网络未授权」；拒绝存储时设置不保存，拒绝打开网页时链接动作不可用。网络配额或服务错误会显示相应状态，公开 API 数据可能变化。

只安装你信任的插件。JavaScriptCore 和 Host 权限提供受限接口，不是每插件独立的操作系统安全边界；当前不能强制抢占无限循环 JavaScript。SuperIsland 兼容仅支持已实现的简单子集，不保证任意上游插件能运行。开发入口见 [SDK 文档](../SDK/docs/README.md)。

## 诊断与反馈

菜单栏选择“复制调试信息”，再选择“提交 Beta 反馈...”，即可把设备、屏幕和面板状态粘贴到结构化 Issue 表单。报告不收集用户名、设备序列号、文件名或歌曲信息；提交前仍请检查剪贴板文本和截图，避免泄露其他私人内容。

真机测试场景与问题等级见 [Beta 验收手册](BETA_TESTING.md)。
