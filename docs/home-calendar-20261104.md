# 分层主页与日程提醒

音乐入口已改为房屋图标的「主页」。主页包含音乐、日历、课程、会议四层。指针位于展开主页内时，触控板双指横向滑动可以循环切换相邻层，也可以直接点击层名称。会议继续向前到音乐，音乐反向到会议；列表纵向滚动和音乐滑块保留原来的交互。设置 → 通用 →「展开时主页默认页面」可选择四层之一，默认音乐并持久保存；每次真正从收起展开时应用。展开中访问拖盘、计时、工具后返回主页保留手动选择，不覆盖计时完成、活动或拖入文件的页面优先级。

选层按钮在主页水平居中。设置 → 通用 →「显示主页选层按钮」默认开启，修改后立即生效并保存。关闭后隐藏整组选层按钮和层数提示，同时收紧主页高度，仍可双指横向切换。切层采用 0.3 秒的渐变缓入缓出；系统开启减少动态效果时直接切换。

## 双指分层导航

- 主页内容区：切换音乐、日历、课程和会议。
- 计时内容区：按标签顺序切换秒表、倒计时和放在计时区域的插件。
- 工具内容区：切换已安装并放在工具区域的插件。
- 岛顶部导航区：切换主页、拖盘、计时和工具；拖盘的普通内容区也可切换这些区域。
- 设置侧栏：切换通用、外观、日历与提醒、插件和关于。
- 设置内容区：切换设置分类；在插件页内则切换已安装、发现、诊断和当前可见的安装页。

每次双指横向滑动只切换相邻一页，惯性不会连续翻页；仅主页四层首尾循环，其他区域与设置分页首尾停止。工具标签栏、文件横向列表、滑块、选择器和输入控件保留各自操作。拖入文件、锁定拖盘、计时完成待确认或展示临时状态提醒时，岛内暂停手势导航；隐藏窗口也不接收手势。

## 接入日历

1. 打开设置 → 日历与提醒，点击「连接日历」，确认系统日历访问授权。
2. Apple 的 iCloud 日历、本机日历以及 macOS 已同步的其他账户日历统一通过 EventKit 读取。
3. Google 日历使用系统账户同步：在 macOS 系统设置 → 互联网账户添加 Google 账户，打开日历同步，等待系统日历中出现日程，再返回刷新。应用不保存 Google 密码或 OAuth 令牌。
4. 勾选需要显示的日历，并按需选择日程、课程或会议分类。课程/会议日历名称及包含会议链接或参与者的日程可自动识别，手动分类优先。

日历层展示未来七天和正在进行的日程，课程与会议层按分类筛选。重复日程使用各次发生时间区分；全天日程展示为全天。可识别的网络会议链接提供加入入口。此版本读取系统日历，不在应用内创建或修改外部日程。

## 提醒

在设置 → 日历与提醒开启「日程提醒」，首次开启需要允许系统通知。可选择开始时或提前 5、10、15、30、60 分钟。只提醒所选日历中的非全天日程，最多安排最近 50 条系统通知。应用运行时还会展示短暂的灵动岛提醒，轮询误差最长约 15 秒；已经安排的系统通知按系统计划投递。

关闭提醒或撤销权限会清理本功能已安排的通知。修改日历选择、分类和提前量后重新安排。全天日程只展示，不发送提醒。退出应用后，已安排的系统通知仍由系统投递；重新启动后刷新最新日程。
