# Dynamic Island 0.6.0 beta.1（未公证开发预览）

App 版本 `0.6.0`，build `3`。本预览首次把 Activity 底座与插件系统一并分发，**不是整体 Plugin 1.0 验收完成或正式稳定版**。原开发计划 39/40 已验收；T39 新作者独立上手、九项跨设备 Beta 场景和无开发环境的干净 Mac 安装仍待验证。

## 本版内容

- 菜单栏提供「插件管理」「导入插件」及诊断，管理页可主动打开「发现」并刷新官方目录。
- 支持 `.dip` 插件包：下载时核对 SHA-256，验证归档路径、体积和 Manifest，预览后才确认安装。安装保持停用，启用不自动批准权限；每项权限可独立批准或撤销，包身份改变后重新审阅。
- 官方[番茄钟 0.2.1 和 GitHub 0.1.0](https://github.com/qyt1340272051-design/DynamicIsland/releases/tag/plugins-0.6.0)可从目录获取。番茄钟现在由插件提供，内置计时保留秒表和倒计时；升级后需要自行安装、授权和启用番茄钟。
- 番茄钟支持 15 / 25 / 45 / 60 分钟、暂停 / 继续、应用内完成提示与本地预设；倒计时不跨 App 重启恢复。GitHub 插件读取两个公开仓库的 CI / PR，不需要 Token，不支持私有仓库。
- 插件工具进入统一工具菜单；工具较多时可滚动选择，选择后有返回岛体的宽限，正常离开收起后清除工具选择。
- 音乐、音量、充电和计时通过统一 Activity 路径呈现；保留 Apple Music、文件托盘与 AirDrop。充电显示更大的进度电池和安全两翼布局，音量提示避开刘海中央遮挡。
- 提供有限的 SuperIsland 兼容子集、独立 SDK 1.0.0、模板、类型和开发手册。兼容范围与原创示例验证见源码文档，不保证任意上游插件可直接运行。

## 下载与安装

本页提供 `Dynamic-Island-0.6.0-beta.1-local.dmg`、对应 `.dmg.sha256` 和 `.json`。在三者所在目录核对：

```sh
shasum -a 256 -c Dynamic-Island-0.6.0-beta.1-local.dmg.sha256
```

DMG 为 Apple Silicon / Intel 双架构，最低 macOS 26.0。打开 DMG，把 App 拖到“应用程序”；升级前先正常退出旧版。构建成功不等于 Intel 或其他设备已实测通过。

本包只有 ad hoc 本地签名，**没有 Developer ID 签名或 Apple 公证**，manifest 中 `notarized=false`。首次打开可能被 macOS 拦截；仅在核对来源与校验和且信任此包后，到“系统设置 → 隐私与安全性 → 仍要打开”手动批准。设备管理策略可能阻止放行，不能保证任意 Mac 双击即运行。不要关闭系统安全机制或删除隔离标记来隐藏安装问题。

## 首个插件

1. 点击屏幕右上角的横向胶囊菜单栏图标，打开「插件管理…」→「发现」→「刷新目录」。
2. 选择官方插件的「下载并查看」，核对名称、版本、来源和权限，点击「安装插件」。
3. 在管理页逐项审阅权限，再启用插件。番茄钟声明本地存储；GitHub 声明网络、本地存储和链接打开。
4. 展开刘海，打开计时工具菜单并选择该插件。默认不安装、启用或授权任何插件。

目录来源与摘要用于发现和完整性核对，不是开发者身份认证。只运行自己信任的代码；JavaScriptCore 的受限 Host 接口和权限 Broker 不构成操作系统级进程隔离，任意无限循环的强制抢占尚不支持。

## 当前边界

- 无自动升级；音乐仅支持系统 Apple Music。AirDrop、系统音量和自动化权限仍依赖当前系统与设备。
- 升级保留原 Bundle ID；普通计时不会跨退出恢复，插件预设和明确授权按包身份存储，不自动继承旧包批准。
- 本机历史实测、自动回归与当前二进制核验分别记录，不把模拟截图、双架构编译或 Host 对象图重建当作跨设备、首次安装或 App 进程重启验收。
- T39 新作者独立按文档构建安装尚待人工走查。真实 Registry 的 Host 网络安装已通过；本机普通 Release 的真实界面也已完成两款公开包的下载、预览、显式安装，核对安装后停用与权限待授权。

完整功能、使用方式和待验收清单见源码中的 README、`docs/USAGE.md`、`docs/BETA_TESTING.md` 和 `docs/plugin-system/PROGRESS.md`。问题反馈请提供版本、设备场景和脱敏诊断，不附私人文件、令牌或音乐元数据。
