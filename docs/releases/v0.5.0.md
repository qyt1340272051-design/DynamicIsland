# Dynamic Island 0.5.0

## 新功能

- Apple Music 进度条可实时拖动；鼠标悬停时显示白色拖动圆点。
- 文件托盘可锁定展开状态、单独移除暂存文件，并提供更清晰的清空反馈。
- 展开岛体新增电源按钮，可直接退出应用；应用图标也已更新。

## 修复与优化

- 修复已播放一段时间后点击“上一曲”却从头重播当前歌曲的问题。
- 秒表、番茄钟和倒计时切换时，岛体、遮罩与内容分阶段同步变化，避免计时数字被裁切。
- 拖动音乐进度时避免轮询覆盖预览，并在切歌或离开界面时安全结束拖动。
- 计时入口由扳手改为闹钟；音乐、文件托盘和计时界面按内容自适应高度，优化展开、文件移除及退出动效。

需要 macOS 26.0 或更高版本。音乐控制仅支持系统 Apple Music，首次使用需授予自动化权限。下载后请核对附带的 SHA-256 文件；真机 Beta 矩阵中的九项场景仍待逐项验收，详细变更见 [CHANGELOG](https://github.com/qyt1340272051-design/DynamicIsland/blob/v0.5.0/CHANGELOG.md)。
