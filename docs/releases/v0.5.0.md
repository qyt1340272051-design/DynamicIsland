# Dynamic Island 0.5.0

这是面向 macOS 26.0 或更高版本的公开测试预发布。DMG 为本地 ad hoc 签名，**未使用 Developer ID 签名，也未经 Apple 公证**；九项真机 Beta 场景仍为待验收，不是正式签名公证版。

## 新功能

- Apple Music 进度条可实时拖动；鼠标悬停时显示白色拖动圆点。
- 文件托盘可锁定展开状态、单独移除暂存文件，并提供更清晰的清空反馈。
- 展开岛体新增电源按钮，可直接退出应用；应用图标也已更新。

## 修复与优化

- 修复已播放一段时间后点击“上一曲”却从头重播当前歌曲的问题。
- 秒表、番茄钟和倒计时切换时，岛体、遮罩与内容分阶段同步变化，避免计时数字被裁切。
- 拖动音乐进度时避免轮询覆盖预览，并在切歌或离开界面时安全结束拖动。
- 计时入口由扳手改为闹钟；音乐、文件托盘和计时界面按内容自适应高度，优化展开、文件移除及退出动效。

下载后请核对附带的 SHA-256 文件，将 App 从 DMG 拖到“应用程序”并尝试打开。若 macOS 拦截，仅在信任文件来源时到“系统设置 > 隐私与安全性”点击“仍要打开”并确认；详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。受管理策略限制的 Mac 可能无法放行。音乐控制仅支持系统 Apple Music，首次使用需授予自动化权限；详细变更见 [CHANGELOG](https://github.com/qyt1340272051-design/DynamicIsland/blob/v0.5.0/CHANGELOG.md)。
