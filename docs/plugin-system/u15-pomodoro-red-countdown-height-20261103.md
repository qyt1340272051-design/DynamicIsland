### 图标颜色的捕获边界

本机的 AppKit `cacheDisplay` 捕获保留了实际已挂载岛体的几何、图标形状和数字，但在岛体遮罩下会丢失 SF Symbol 的着色。不能把这条捕获路径中的白色图标直接当作屏幕最终颜色，也不能用整张 `ImageRenderer` 输出替代原生岛体截图：后者无法完整合成隐藏的 AppKit 控件，可能出现与图标无关的平台视图占位区域。

本轮分别保留原生 AppKit 捕获和 SwiftUI 颜色参照。在原生截图中定位真实计时图标后，只在该图标外扩一档倍率的有界区域内检查红色像素；比较宽高，并在最多一像素平移后计算掩码 IoU。三档倍率记录的 IoU 约为 0.667、0.854、0.780，均超过 0.6 门槛；红色掩码面积也受原图标面积约束，避免将宽大的红色占位块当成正确图标。

这些证据支持「当前节点请求红色、SwiftUI 将同一计时符号绘为红色、原生图标与颜色参照形状对应」及实际原生画布的几何结论。颜色参照的局部截图属于独立参照，不冒充整张原生窗口或物理设备验收截图。原始捕获、参照与局部图标文件由本地交付目录保留。
