# U03 — 音乐页收紧与统一设置（2026-10-26）

用户新增两项范围：降低音乐展开页高度；在岛内退出按钮旁增加设置入口，并创建通用、外观、插件、关于四个页面。随后用户要求主导航改为左侧纵向排列，并修正插件子页面按钮的错位。

本批目标为 App 0.6.0 / 未发布开发 build8。SDK 1.0.0、原插件任务表、公开构件与历史 build7 的人工结论分别保留。

## 实现

- 音乐页设计高度由184降至172，内容预算由134降至122。时间、播放进度与总时长共用一行；保留112设计点封面、28设计点按钮及原有播放、跳转、进度和音量操作。展开密度仍为0.88，按最终point原生绘制。
- 岛内新增齿轮按钮，位于退出按钮左侧。菜单栏“设置…”和⌘,也打开同一原生Settings场景；原插件管理、诊断、文件导入和目录下载入口均路由到该场景。
- 主导航位于159点宽的左侧栏，四项纵向等距排列。右侧插件顶部栏包含已安装、发现、诊断，以及需要时出现的安装页；子页按钮统一76×28、间距6、左右栏内边距16，导入按钮同高并右对齐。最小内容尺寸960×640，保留原管理页800×600预算。
- 通用提供现有显示/隐藏操作；外观先提供当前显示方式说明；关于读取当前Bundle版本与构建并提供复制诊断信息。没有加入未实现的偏好开关。
- 插件管理、权限确认、安装预览、目录和诊断复用原模型及视图。切页保留安装预览；发现页不会自动联网，离开或关闭窗口取消目录刷新。关闭窗口时仍须等待安装取消/清理，清理失败保留窗口和准确的预览，允许重试。
- 应用入口采用AppKit生命周期，并通过macOS26公开的NSHostingSceneRepresentation注册一个SwiftUI Settings场景，使岛的独立NSHostingController可可靠打开设置。保留设置、编辑、窗口、隐藏及退出菜单操作。

## 验证记录

首轮完整回归执行1157项，3跳过、1失败；唯一失败是旧测试将Host最大高度184与音乐专用高度172视为相同。已将两者分别断言，保留插件184→134预算与超限裁剪检查。

新设置专项覆盖真实AppKit点击、四页切换、最小窗口内容、显式目录刷新/下载、切页保留预览、取消清理、原窗口代理转发与清理失败重试。侧栏和插件栏另外根据实际渲染文字位置验证纵向/横向对齐；图标被OCR识别为文字前缀时，只测标签子串的字形边界。

最终完整回归执行1157项：1154通过、3跳过、0失败，Release构建及签名完整性检查通过。三个跳过项为显式开启的GitHub公网测试、Registry公网安装测试和单独生成的截图矩阵；不表示这些公网路径在本轮得到新验收。原生设置专项6项和岛内齿轮点击已包含在最终完整结果中。

普通Release build8实际运行后，⌘,打开设置、主侧栏与插件发现页布局、⌘W关闭、⌘,再次打开并保留页面均已确认；发现页保持离线初始提示，未点击联网刷新或变更插件授权。旧调试版已正常退出，当前仅运行新Release。跨分辨率模拟矩阵另行成功生成144张，校验全部清单与摘要，抽查5张完整音乐岛体未见裁切，齿轮与退出按钮相邻并位于相机范围外。合成截图不替代用户的实际观感；[结构化证据与选图](evidence/u03-settings-build8-20261026/README.md)单独保留。

## 人工范围

build8新增音乐高度的主观观感、不同真实分辨率下的设置窗口与岛内齿轮入口仍待用户确认。自动化的原生点击和模拟布局结果不替代这一结论。build7的已有视频、长菜单与两翼证据仍只支持其原范围；本批未关闭其余U02人工项目，也未播放音乐或改变系统音量、分辨率及菜单栏偏好。
