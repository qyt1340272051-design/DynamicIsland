# U08 — 计时与工具分区（2026-10-28）

用户要求取消点击工具按钮后的弹出菜单，让计时区仅放计时相关功能，另设工具按钮；功能插件可在设置中选择区域；选择方式改为岛内分页，类似现有秒表/倒计时。

目标为 App 0.6.1 / 未发布 build14。该范围不改变插件 Manifest、SDK接口、启用状态或授权规则。

## 实现

- 闹钟按钮打开计时区，横向切换栏包含秒表、倒计时，以及用户分配到计时区的插件；独立工具按钮展示其他插件。工具默认进入工具区。
- 切换栏在岛内，内容较多时横向滚动；生产 `IslandView` 不再使用 `IslandToolMenu`，也不创建菜单跟踪/返回保持。旧菜单代码和历史验收保留，不冒充新版行为。
- 主工具栏左侧为音乐、托盘、计时；右侧为工具、设置、退出。三项分别位于刘海两翼，以保持相机区域空白。
- 设置 → 插件 → 已安装 → 选中插件 → 显示区域，提供计时区/工具区选择。纯音乐来源插件仍使用音乐来源选择；功能与音乐混合插件可以配置工具区域。
- Host单独保存插件ID到区域的映射，位于插件State目录。提交成功后同时更新设置和Runtime；保存失败保留原区域并显示错误。选择跨禁用/启用、版本更新与App重启保留，不触发插件执行或授权。
- 原生计时复用原有高度；插件分页在外层增加24+4设计点，保持原184设计点Host画布、134设计点渲染内容预算。新增分页不会迫使插件退回摘要或丢失控制按钮，音乐尺寸不变。
- 选择、请求展示和动作继续绑定准确Activity实例。改区时只清除受影响的工具；不打断无关插件的请求期限/预算。高优先级提示仍沿用原有优先级及恢复规则；收起、隐藏、拖动和页面切换按原规则结束工具选择。

## 验证

定向测试184项通过；随后运行时与实际AppKit窗口35项通过，包括区域过滤/路由、保存/重启、禁用插件配置、权限与执行状态不变、失败回滚、旧预览拒绝、无关请求不受影响、真实区域按钮与岛内分页点击、横向溢出滚动和三档模拟几何。初轮编译时的过渡性穷尽switch错误保留在各自日志中，不计为测试通过。

首轮完整回归1255项、3跳过、7个失败断言，均来自旧菜单交互测试仍假设所有工具都位于计时页：五个区域断言和一个区域等待条件造成一次附带超时异常。已按通用工具默认工具区更新测试预期，保留全部选择、动作、期限、触觉反馈和正常收起检查；不删除或跳过历史测试。

最终完整回归1255项、1252通过、3跳过、0失败；普通Release构建与签名核验通过。144张模拟矩阵生成并校验，抽查22张矩阵/原生窗口图片未见裁切或按钮进入相机区域。详见[结构化结果](evidence/u08-tool-regions-build14-20261028/result.json)。合成UI和存储测试不等同于当前设备的主观观感与真实重新启动验收。随后用户提出番茄钟样式修改，继续进入build15；不将build14已验证二进制与后续工作区视为相同输入。

## 人工保留

按用户先保留人工操作的既有安排，下次可集中确认：点击两个入口无弹出菜单、计时/其他插件分页易用且无遮挡、实际触控板横向滚动、在设置修改区域并重新启动App后仍保留。无需重新批准插件权限；不为这次UI验证播放或控制音乐。
