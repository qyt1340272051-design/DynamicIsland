# U04 — 按需安装的网易云音乐适配（2026-10-26）

用户授权：将网易云音乐作为可选插件提供，未安装用户不下载播放器适配与媒体辅助脚本。此项扩展现有 JS 插件系统，开发目标为 App 0.6.1；首轮 build9 与封面修正后的 build10 分别验收；不改写 0.6.0 与 SDK 1.0.0 的历史验收。

## 实现边界

- 主程序只负责播放器注册、已有音乐界面、来源选择、权限与有界辅助进程通信。网易云专用 JXA 脚本仅随独立 `.dip` 分发，不放入 App 资源。
- `mediaProvider` 声明目标 Bundle ID、显示名、脚本路径与 SHA-256。Validator 从安全文件描述符读取不可变脚本快照；授权指纹包含声明及脚本内容。
- 首版只允许 Host 固定摘要的官方辅助脚本。普通 JS 插件不能执行 shell、启动自选进程或调用任意原生对象。辅助脚本更新需要相应 Host 信任摘要更新；自报开发者或包内摘要不等于信任。
- `media.read` 与 `media.control` 分别显式授权；安装、启用、选择来源不会自动批准。权限撤销、停用、休眠与卸载关闭执行会话并取消待处理请求。
- 通用设置提供播放来源选择。旧来源的封面、曲目及拖动会话在切换时清除；旧异步结果不得覆盖新来源，也不得把旧按钮操作转发给另一个播放器。
- 不实现账号登录、Cookie 读取、歌单管理或音源下载。使用已安装网易云桌面端发布的系统媒体信息。底层 MediaRemote 属于私有系统接口，实际支持范围随实机验证记录。

## 验证要求

1. 兼容旧 Manifest，拒绝无效描述、摘要不匹配、路径穿越、未知权限及缺失辅助文件。
2. 安装默认停用；逐项授权、撤销、包更新后的重新授权、停用与卸载可审查。
3. Mock 验证路由、来源隔离、进度曲目身份、超时、取消、资源上限及旧结果丢弃。
4. 正式打包独立 `.dip`，检查 App 无插件资源与未安装时无辅助进程。
5. 完整回归和 Release 构建；实机歌曲、封面、切歌与拖动只有在真实播放器行为完成后才记录通过。

## 当前状态

实现及当前设备的核心播放闭环验收完成，当前运行版本为 0.6.1 / build10；未公开发布。build9 的真实播放补验、build10 的完整回归及普通 Release 封面缓存复验分别留存。2026-10-27 已恢复继续验收前的网易云曲目、暂停状态和位置，恢复 Apple Music 来源并撤销两项临时媒体权限。

## 真实播放与封面修正

用户明确批准临时读取与控制网易云，并要求验收后恢复 Apple Music 来源、撤销两项媒体权限。build9 实机已观察到紧凑封面、展开曲目字段及播放按钮状态变化；暂停 / 恢复通过。媒体 API 的下一首、上一首、进度跳转和过期曲目身份拒绝均通过；切换后的封面存在。用户另行确认真实鼠标拖动进度，观察位置约为 1 分 2 秒且保持暂停；原生滑杆增量输入与物理拖动作为不同证据记录。

实测也发现：系统有时同时省略封面回调与原生封面数据，未返回错误，此时界面会显示占位图。build10 新增按播放器、曲目字段及时长匹配的内存缓存，上限 8 张 / 合计 8 MiB；不修改用于控制和进度跳转的曲目身份。切换来源、读取权限变化或停止会清理缓存，仅撤销控制权限保留已获准读取的封面。2026-10-27 普通 build10 已实际复验：返回上一首并继续播放后，原始系统查询无封面，紧凑岛仍显示此前收到的正确封面。首次读取且尚未缓存的歌曲，如系统未提供封面，仍可能显示占位图。

结构化结果与设置截图见[验收证据](evidence/u04-optional-music-20261026/README.md)，真实播放记录见[播放补验](evidence/u04-optional-music-20261026/playback-verification.json)。曲名、歌手和封面内容不写入结构化记录。最终已确认两项权限均为 revoked、所选来源为 Apple Music、辅助进程为 0。上次中断后用户已改变播放，故本次恢复继续验收时观察到的曲目、暂停状态与约 13.3 秒位置，没有强制切回前一轮曲目及 0 秒。其他播放器同时活动、长时间自动换曲和跨系统版本兼容未补记为通过。
