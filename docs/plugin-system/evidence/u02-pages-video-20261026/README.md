# U02 build7 — 高分辨率页面高度转场录像摘要

本记录归档 build7、2560×1664 档位下的页面切换录像统计。原片及提取图像仅留在私有验收目录；本目录只保存数值、来源摘要与判定边界，不包含原片路径或桌面内容。结构化结果见 [result.json](result.json)。

原片裁切尺寸为 1150×336，时长约 129.443 秒，顺序解码全部 **6424 帧**，未主动跳帧。去除录屏选区覆盖的 237 帧后，6187 帧中有 **6077 帧**满足双侧安全探针条件；其余 110 帧因形状或侧缘裕度不足排除。6077 帧双侧顶边偏移均为 **0px**，探针顶行 RGB 单通道最大值为 2，黑色阈值为各通道小于 12。

私有复核记录覆盖托盘→音乐→秒表→倒计时→托盘→音乐的 **5 次高度转场、76 个采样帧**。每个括区包括变化前稳定帧和首次达到目标高度的帧，76 帧均满足双侧探针条件、顶边偏移均为 0px；每次转场各有一个真正中间帧经过人工查看。本次公共归档复算了原始与复核后的 CSV 统计，未重新操作 UI。

原始记录的五个括区内部相邻帧最大间隔均约 **33.333ms**；九位小数时间戳相减的最大值为 0.033333334 秒，差异来自舍入。私有报告总述中的 **50ms** 对应第二个括区开始前的 1636→1637 帧，而非括区内部。本公共结论采用转场采样间隔 **不超过 50ms** 的保守上界。全片最大间隔为 **4.25 秒**，发生在前段静态内容，不能把转场采样密度推广到全片。

原始几何判定为双侧安全 6250 帧、仅单侧安全 2 帧、双侧均不安全 172 帧。原始 **175 条右探针 1px 异常**全部保留统计；它们出现在 125.281666667 秒起的录屏选区覆盖之后，范围为帧 6187–6361。私有复核确认选区边界遮住探针 y0、y1 仍为黑色，因此底层 y0 无法判定，不能据此计为软件离顶缝隙。自帧 6187 至片尾共 237 帧全部按覆盖排除，不只排除异常帧。

探针中心位于视频 x406、x778，各取 x±1 三列、前 30 行，位于 312px 相机预留区之外；安全条件要求探针在半高黑色包络内且距两侧各至少 48px。壳体高度是中心三列估计的视频像素值。Compact 或圆角侧缘使探针落到壳体外时按形状排除，不算 gap；半高包络被内容打断时也可能保守排除。

结论只支持本片五次转场中已捕获、安全双探针处未见顶边缝隙；不能证明未录到的瞬间、所有横向像素或相机遮挡区域。片尾 128.215–128.615 秒收起过程受选区顶边覆盖，不能作完整双探针 y0 结论。本记录不覆盖默认分辨率、菜单栏显隐、真实分辨率切换或其他 Activity 场景，也不关闭整组 M-U02-C。
