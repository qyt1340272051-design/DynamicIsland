# beta.2 当前设备部分实机观察

本地日期：2026-10-22（Asia/Shanghai）。[结构化记录](di-b01.json)对应原样公开 `v0.6.0-beta.2`，App 0.6.0 / build 4；不是历史隔离 build3，也不是干净 Mac 安装验证。

## 本轮已观察

- 原样公开包启动，签名和可执行文件摘要与发布构件一致；数据已在私有目录备份，备份未归档。
- 实际悬停展开、移出收起。用户确认当前分辨率的秒表两侧显示正常，同时要求后续增加全分辨率自适应；这不构成其他缩放模式通过。
- 秒表开始、时间推进、紧凑态时间、暂停、继续及重置；倒计时长按从 5 分钟减到 1 分钟，真实自然完成并点击确认收起，最后恢复 5 分钟预设。
- 岛内音量加减、静音和取消静音。初始控件测试最高 6.25%，之后恢复 0 和静音。用户键盘输入期间 AX 记录多次 38%–69%–44% 变化，重新展开为 44%，最终再次恢复 0 和静音；不能把这段记作单次按键或全程低音量测试。

## 当前未通过的范围

`DI-B01` 继续 **pending**。尚未确认默认缩放、菜单栏常显、逻辑屏幕几何；未完成滑杆交互、物理屏幕上的音量提示完整性、真实 Apple Music、文件托盘流程、当前发布包的官方插件流程、显示隐藏及正常退出等检查。`DI-B02` 未执行，其他七项硬件场景及干净 Mac 安装也未执行。

用户暂不播放音乐。工具对音量滑杆的 `setValue` 不支持，一次原生拖动报告 `noWindowsAvailable`，因此不记滑杆通过，也不据此判定产品失败。音量 HUD 的 AX 与原生 App 窗口截图不能证明物理刘海周围的完整呈现。全屏幕顶边和其他缩放对照仍需实测。

文件托盘初始 UI 为 0，但临时目录候选存在两项既有普通文件，空目录前置条件不成立。保留既有文件，不执行清空或 AirDrop。仅准备了合成文件 `DI-B01-test.txt` 和人工拖入步骤，当前尚未记录导入完成。
