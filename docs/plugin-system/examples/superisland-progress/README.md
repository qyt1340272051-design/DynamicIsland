# 兼容·进度

DynamicIsland 独立编写的 SuperIsland 协议示例。点击「下一步」将手动进度从 0/4 增加到 4/4，进度归一化为 0…1；「归零」重置。没有定时器、网络或系统资源访问，再启用回到零。

「请求展示」与「撤回请求」仅向 Host 提出意图。已有用户工具选择时，请求不能覆盖该选择；撤回也不会关闭用户展开的窗口或结束 Activity。Host 仍执行实例、优先级、场景和期限检查，拒绝不是插件崩溃。

安装后保持停用，启用无需额外系统权限。presentation.request 是能力声明，不是窗口控制权。所有字体、间距、图标、颜色和按钮采用 Host 样式，管理页显示有限兼容。
