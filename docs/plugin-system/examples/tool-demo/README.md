# 工具选择示例

T35 工具选择与公开动作链路的最小验证包。无权限、后台任务或计时器。

安装并启用后，在刘海展开的「计时」菜单选择「工具选择示例」，点击「增加一次」观察计数。切换到音乐、拖盘、内置计时或收起刘海会清除选择；再次展开需重新选择。停用、卸载和重载使旧实例选择失效。提示抢占时，工具动作无法执行，提示结束后可恢复原选择。

`presentation.role: 'tool'` 仅用于 persistent / progress Activity，Host 将插件工具优先级限制为 background。未选中的工具保留在工具列表，Host 决定何时呈现。此示例不是番茄钟实现；精确倒计时按后续 T35 子步骤推进。
