# 番茄钟官方插件 0.3.1

包 ID：`com.dynamicisland.pomodoro`；开发者：DynamicIsland。需要 Host 0.6.1；开发构建须为 **build20 或更新**，以支持红色图标与 174 点计时布局。

## 使用

在「插件管理 → 发现」刷新目录，确认番茄钟版本为 0.3.1 后下载并检查安装信息；也可导入对应 `.dip`。安装后启用插件，根据「显示区域」在计时区或工具区选择番茄钟。新包默认停用，安装和启用均不会自动授予权限。

预设为 15、25、45、60 分钟，首次默认 25 分钟。加减按钮逐档切换预设；运行时禁用时长调整，最短和最长时长会禁用对应方向。主按钮用于开始、暂停和继续，副按钮结束本轮。暂停时修改时长会结束原计时并回到准备状态；结束后保留当前预设，不自动开始下一轮。

0.3.1 使用番茄红 `danger` 色表现状态、主按钮、进度、收起图标和时间。展开的大号时间保持白色，底部仅显示进度条。右侧仅保留预设和操作两行；展开高度与内置倒计时相同，字体和圆形按钮尺寸保持原有计时样式。收起倒计时由 Host 按实际时间宽度布局；计时中再次展开会恢复当前工具页面。

## 权限与计时

唯一权限是 `storage.local`，用于保存预设与设置。拒绝或撤销后，计时与应用内完成提示仍可使用。没有系统通知、网络或其他权限。包代码变更后，旧版授权不自动适用于新代码，须在 Host 中重新确认。

时间和进度引用 Host 倒计时的精确 generation；开始和继续需要真实用户动作的一次性 activation。JavaScript 不持有秒级定时器，收起或隐藏工具不会结束计时。Host 完成事件核对当前 generation 后显示一次应用内「专注完成」提示，不自动重新开表。

Host 倒计时记录不跨主程序重启保存，存储中的 `lastSession` 仅为元数据，不能恢复或自动开始计时。

## 设置与后台对账

设置只使用 `settings` 一个 key，格式不变：

```json
{"schemaVersion":1,"selectedMinutes":25,"lastSession":"idle"}
```

仅接受以上三个字段、合法预设和 `idle` / `running` / `paused` / `completed` 状态。非法数据回到默认 25 分钟，不在启动时覆盖原值。活动中的 Host 记录优先于存储设置。

设置通过一份在途写入与一份最新草稿保存；失败不循环重试，下一次动作或唯一后台 refresh 可以重试。每次插件执行只请求一次 `requestRefresh(30000)`，Host 保留后台与低功耗调度下限。晚到的读取不会覆盖用户已更改的预设。
