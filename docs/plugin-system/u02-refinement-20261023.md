## 实现

- **清晰度**：保留 auxiliary 刘海高度 / 32 的布局倍率，将字体、SF Symbols、电池路径、间距、按钮与图片直接布局到最终显示 point。移除整岛的放大变换和合成分组；实际 backing scale 仍由系统提供，避免把较小的组合图再放大。Slider / Toggle 使用系统尺寸档位与最终字号；计时模式选择器改用明确原生字体和尺寸的 NSSegmentedControl，保留目标动作、Binding、键盘与无障碍。仍需实机检查外观和交互。
- **贴顶**：`IslandShellShape` 的路径从容器 `minY` 开始，移除原先形状居中与反向位移相抵的双重动画。扩张、收缩和页面高度变化只改变路径尺寸，顶边始终固定。
- **收起两翼**：`IslandCompactLayout` 分别测量图标、时间和百分比的预算，保留相机间距。两翼不等宽时只移动外壳中心，不移动实际相机避让区；绘制与 Controller 悬停使用同一布局。百分比预留 `100%`，原生计时只在格式宽度变化时发布外层宽度更新。无安全 spacer 或超 Host 预算的插件树回退 minimal / Host 图标，保留 Activity 与动作路由。
- **展开尺寸**：设计宽度 480 → 440；音乐 / 工具画布高度 200 → 184，倒计时 / 完成态 190 → 174，非空托盘 164 → 148，秒表 / 空托盘 152 → 136。内容高度随当前壳体变化，避免仍按最大高度布局后再裁切。计时与托盘内部同步调整，保持按钮和两行文件名空间。

SDK 1.0.0 的源码、Node 词汇与权限语义保持原版本；Host 画布是 App 的布局策略，不是插件可指定的像素尺寸。未修改公开 beta.2 或发布资产。

## 2026-10-24 自动收尾

用户要求继续工作并保留人工部分。当前代码额外修正了审查发现的非对称长叶节点被旧428点画布截断、悬停反馈越过固定面板边界；实际壳体与悬停区共享同一最大宽度计算。

迭代中保留了真实失败：较短页面在184点容器内默认居中下移，导致托盘第二行被切；计时内容竖向压缩使26点数字微缩；原生Progress固定20点、Slider按mini/small/regular产生12/14/16点固有高度，导致归一化内容高度不同。分别用顶对齐、自然内容高度与更小间距、随倍率解析的Host行高修正，未通过放宽页面高度比较规避。原生字体五个token的语义字形与preferred字体像素误差为0，单行/三行自然排版对照通过。

路径边界比较只对CGPath的单精度宽高/水平中心允许0.0001点误差，顶边仍检查0.000001点；原生NSButton允许最多1点AppKit尺寸取整，内外转换倍率、实际命中与菜单锚点检查保留。完整自动结果与新截图在本节继续追加。


截图审阅另发现SwiftUI分段Picker没有消费外层最终字号，2560合成档的选择器偏小；改为原生NSSegmentedControl，明确12×倍率字号和120×24×倍率布局，并新增实际NSControl字体/尺寸与Binding动作检查。此前全量v2的成功记录保留为该修正前的独立结果，最终回归另行记录。
