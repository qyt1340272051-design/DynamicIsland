## 问题与修正

[用户截图](evidence/tool-menu-hover-20261020/user-report.png)中的七项工具菜单延伸到岛体下方。原工具选择器使用 SwiftUI Menu，窗口悬停只覆盖岛体；指针离开立即令 `isHovering=false`，Runtime 会同步清除工具选择。原 350ms 延迟用于进入展开，不是选后返回缓冲。

- [原生工具菜单](../../DynamicIsland/IslandToolMenu.swift)由 Host 拥有 NSButton / NSMenu。进入菜单跟踪前取得会话，跟踪期间保持展开，菜单项冻结打开时的实例快照。当前修正以 popUp 返回作为跟踪结束边界，先将完整返回宽限交给 ViewModel，再核验 token 并执行冻结的选择；正常选中引起的旧控件重建不再撤销已移交的宽限。
- [ViewModel](../../DynamicIsland/IslandViewModel.swift)保留物理 `isPointerInside` 与有效展开 `isHovering` 的区别。菜单期间即使指针在岛体之外，Runtime 仍看到连续的展开状态；关闭后提供 **1 秒**返回缓冲。宽限内返回立即继续当前工具，不重新触发展开延迟、页面选择或触觉反馈。
- 菜单关闭时始终提供宽限，包括默认模式的指针轮询尚未更新、仍留有旧 inside 值的情况。宽限内短暂进入 / 离开不会提前消耗或延长原截止时间。过期后若指针仍在外侧则正常收起，并沿用原来的同步清选择和旧动作拒绝策略。
- 跟踪期间禁用 / 拆卸控件，以及真实隐藏、切到音乐 / 拖盘、拖入文件、计时完成及 shutdown 仍会结束对应会话；移交后的旧控件正常替换不拥有 ViewModel 的返回宽限。旧菜单回调与旧宽限不能复活展开或覆盖新会话。保持只作用于 Host UI，没有新增插件能力或权限。
- 保留 28pt 图标及 selector / item 标识。NSMenu 负责屏幕边缘约束、超长列表的系统滚动、键盘导航与取消；这些原生交互仍需实际界面确认，不把使用系统控件本身写成实测通过。

## 首次物理验收失败与修正（当前）

用户先后反馈“停顿半秒后自动收起,重新展开之后显示的是秒表界面”和“停顿半秒后自动收齐,重新展开后显示秒表界面”。这是**同一轮操作的两条同义报告**，不是两轮独立失败。该轮没有满足选择底部工具后稍缓返回仍保持当前工具的要求，U01 不能因先前 AX 成功而标记通过。

助手后续的[原始截图](evidence/u01-menu-20261020/after-user-reported-premature-fold.jpg)与[AX](evidence/u01-menu-20261020/after-user-reported-premature-fold.txt)仅记录到收起状态，未拍到重新展开后的秒表界面。因此“重开显示秒表”依据用户直接反馈，不写成截图已经像素佐证该页面。

失败发生时尚无本次新增的原生菜单 / ViewModel 回调事件日志，**不能确定那次究竟经过了哪个具体 callback 分支**。审查发现并修正以下可复现或可避免的机制，不把它们全部写成已确认的旧现场根因：

1. **先移交宽限，再执行选择。** 原生菜单结束跟踪后，冻结选择并清空旧 Coordinator 的活动会话 / delegate / pending；ViewModel 先承接完整返回宽限，再按有效 token 执行选择。选中同步发布 Activity 或改变壳体所引发的旧控件重建，不再取消已经移交的宽限。真实隐藏 / 拖动 / 会话失效仍拒绝迟到选择，未放宽跟踪期间的真实拆卸取消。
2. **移除 `didClose` 硬门槛。** `popUp` 返回已表明该次原生跟踪结束，不再要求 `menuDidClose` 必须先于目标动作或函数返回；仍保留 token、启用状态及移交前控件有效性的校验。
3. **保留原返回截止时间。** 原 ViewModel 在宽限内第一次收到 inside 样本就清除了宽限，随后一次短暂 exit 会立即收起。当前改为短暂 entry / exit 不提前耗尽宽限，也不因反复 entry 延期；原截止时间到达时按最新物理 inside 值决定是否正常收起。

新增的两项指针抖动测试在旧 ViewModel 上实际先失败：**2 tests / 8 assertion failures**，日志 `/tmp/dynamic-island-u01-repair-20261020/grace-before-fix.log` 保留。修正后合跑 **92 tests / 0 failures**，包含菜单交互 14 项、既有 ViewModel 50 项、Runtime 24 项和 Hover Region 4 项；另两项新完成回调测试覆盖宽限先移交、同步控件失效与 token 撤销。这是有界定向回归，不是完整 CI 或真人过渡验收。

本次还增加 `ToolMenu` 类别的低频事件日志，仅记录固定事件码、随机会话 token 和可选布尔状态，不记录插件名称 / ID 或指针坐标，用于下一轮真实路径核对。修正与回归材料见[修正证据说明](evidence/u01-menu-repair-20261020/README.md)和[结构化结果](evidence/u01-menu-repair-20261020/result.json)。

修正版普通 Release 构建及 strict / deep 签名已通过，来源见[新预检](evidence/u01-menu-repair-20261020/preflight.json)。此前失败副本 PID 19822 已正常退出，新副本“Dynamic Island Menu Repair”（PID 22058）已启动并开启事件记录。已请求用户直接完成第二轮物理选择 / 停顿 / 移回，结果仍待反馈；当前不声明用户返回通过或 U01 完成。
