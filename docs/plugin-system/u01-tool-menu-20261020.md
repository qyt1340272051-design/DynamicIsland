## 问题与修正

[用户截图](evidence/tool-menu-hover-20261020/user-report.png)中的七项工具菜单延伸到岛体下方。原工具选择器使用 SwiftUI Menu，窗口悬停只覆盖岛体；指针离开立即令 `isHovering=false`，Runtime 会同步清除工具选择。原 350ms 延迟用于进入展开，不是选后返回缓冲。

- [原生工具菜单](../../DynamicIsland/IslandToolMenu.swift)由 Host 拥有 NSButton / NSMenu。进入菜单跟踪前取得会话，跟踪期间保持展开，菜单项冻结打开时的实例快照。菜单关闭与动作回调不假定先后顺序；实际选择在 popUp 返回后执行，然后结束保持。
- [ViewModel](../../DynamicIsland/IslandViewModel.swift)保留物理 `isPointerInside` 与有效展开 `isHovering` 的区别。菜单期间即使指针在岛体之外，Runtime 仍看到连续的展开状态；关闭后提供 **1 秒**返回缓冲。宽限内返回立即继续当前工具，不重新触发展开延迟、页面选择或触觉反馈。
- 菜单关闭时始终提供宽限，包括默认模式的指针轮询尚未更新、仍留有旧 inside 值的情况。过期后若指针仍在外侧则正常收起，并沿用原来的同步清选择和旧动作拒绝策略。
- 取消、禁用、隐藏、拆卸、切到音乐 / 拖盘、拖入文件、计时完成及 shutdown 会结束对应会话。旧菜单回调与旧宽限不能复活展开或覆盖新会话。保持只作用于 Host UI，没有新增插件能力或权限。
- 保留 28pt 图标及 selector / item 标识。NSMenu 负责屏幕边缘约束、超长列表的系统滚动、键盘导航与取消；这些原生交互仍需实际界面确认，不把使用系统控件本身写成实测通过。
