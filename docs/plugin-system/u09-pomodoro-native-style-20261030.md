# U09 — 番茄钟采用内置计时样式（2026-10-30）

用户要求将番茄钟插件改为内置秒表/倒计时的布局风格。目标为开发中 App 0.6.1 / build15，独立番茄钟插件0.3.0；公开Registry和已有0.2.1资产保持原版本，不自动发布。

## 实现

- 左侧为状态和26设计点等宽时间，右侧为预设时长与圆形操作按钮，下方为4设计点进度条。时间、32设计点主/副按钮与进度尺寸和内置计时共享Host常量；小型加减按钮使用已有控件尺寸。
- 加减在15、25、45、60分钟预设之间切换；运行时禁用，边界按钮也禁用。主按钮根据状态显示开始/暂停/继续，副按钮重置。保留现有八个动作、Host倒计时generation、后台期限、完成提示和存储逻辑。
- 继续作为独立插件。紧凑/minimal原有树及行为不变，区域仍由U08中的用户选择决定。
- 使用通用受限样式，不按插件ID定制Renderer：Text有限font、Button有限style/color/isEnabled、timer倒计时文字和track细进度条。旧默认编码与样式保持原值，拒绝任意尺寸、无效枚举、null和非布尔enabled值。
- 展开Host允许的树深度从5放宽到6，以容纳两列中的按钮图标；保留32节点、8动作及其他预算。本插件最大25节点、6层、5行，完整保留134设计点内容区。

## 交付与人工范围

新版插件使用新增Host样式，须配合build15及后续支持这些样式的0.6.1 Host。源清单已声明最低Host0.6.1；0.6.1本身仍为开发版本，不能据此保证早期build12等开发构建兼容。

新插件沿用storage.local且数据格式不变。按照既有Host规则，代码升级会要求重新确认该版本的存储授权；本批不绕过指纹确认，也不自动重启用户正在运行的番茄计时。实际导入、授权与主观观感保留到下一次人工验收。原T01–T40、U02–U08及公开版本的历史结论保持各自范围。
